# Harness self-checks (oracle test double)

The oracle answers from gold labels, so these runs test the pipeline plumbing and the metric code, not a model. The clean run should score at or near the ceiling. The noisy run injects missed events, date shifts and altered quotes, and shows that the metrics and the grounding validator respond. **Oracle limits:** it only emits gold events and copies evidence lines mechanically, so the issue and memo numbers show that the plumbing works (grounding, verification, scope and injection checks), not that the analysis is good.
