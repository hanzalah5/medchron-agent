# Synthetic smoke set

> **All data here is synthetic.** It was generated by `medchron synth`. Every page carries a "SYNTHETIC RECORD - NOT A REAL PATIENT" banner. No real patient, provider or client is described.

Each case is a single PDF **record production**, plus a gold-label JSON file (`CaseGold` in [`src/medchron/synth/models.py`](../../src/medchron/synth/models.py)).

| File | Contents |
|---|---|
| `case_NNNN.pdf` | The production: fax cover sheets, multi-provider records grouped by facility (not chronological), duplicate pages and scanned pages with **no text layer** (OCR required) |
| `case_NNNN.gold.json` | Gold labels: document index with page ranges, clinical events with verbatim quote and page sources, planted issues and per-page ground-truth text |
| `manifest.json` | Per-case summary: scenario, page, event and issue counts, PDF SHA-256 |

Regenerate the set with:

```bash
medchron synth --cases 5 --start-seed 1 --out data/synthetic
```

CI checks that the committed gold labels can be reproduced exactly from their seeds. PDF bytes are deterministic for a given seed and library version.

## What the benchmark tests

| Challenge | How it is planted |
|---|---|
| Messy layout | Records grouped by facility, fax headers, page `x of y` footers, mixed date formats (`03/14/2024`, `March 14, 2024`, `14-Mar-2024`, …) |
| OCR | Randomly chosen pages rendered as rotated, speckled scans with no text layer |
| De-duplication | Pages re-sent at the end of a facility's production (`duplicate_of` in gold) |
| Grounding | Every gold event has verbatim quotes on exact pages. Matching normalizes whitespace. |
| Issue detection | `date_conflict`, `missing_record`, `record_inconsistency`, `potential_delay` |
| Safety | `prompt_injection`: a fax cover with instructions addressed to automated systems |

## Scenarios (simplified and illustrative, not clinical guidance)

- `abdominal_pain_return_visit`: ED discharge with a gastritis impression, then a return visit with perforated appendicitis, appendectomy and a wound infection.
- `knee_replacement_vte`: knee replacement, an anticoagulation change at discharge, then calf swelling followed by DVT and PE.
- `wrist_fracture_overread`: a negative preliminary x-ray read, a radiology over-read showing a scaphoid fracture, late notification, then ORIF.

Planted issues are written as **questions for expert review**, matching how the system is meant to report them.
