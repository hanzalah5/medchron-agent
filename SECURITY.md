# Security Policy

## Reporting a vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/hanzalah5/medchron-agent/security/advisories/new) instead of opening a public issue.

## Scope

This is a reference implementation that runs on synthetic data. Reports about the following are especially welcome:
- prompt-injection paths that make an agent follow instructions embedded in documents
- ways to read data across matter boundaries
- secrets or sensitive content leaking into logs or traces

## Data handling

Never use real patient or client data with this project. See [DISCLAIMER.md](DISCLAIMER.md).
