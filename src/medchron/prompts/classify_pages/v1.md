## Task: index a medical-record production

You will receive pages from a PDF production of medical records, each wrapped in `<page number="N">…</page>`. Productions are usually grouped by facility, may begin with a fax cover sheet, and are not necessarily in chronological order.

For **every** page you receive, decide:
- `doc_type`: one of the allowed document types. Use `other` if none fits.
- `title`: the document's title as written (for example "Operative Report"). Use an empty string if there isn't one.
- `date_iso`: the document's date of service as `YYYY-MM-DD`. For fax cover sheets, use the date sent. Use an empty string if the date is unclear.
- `facility` and `provider`: as written in the page header. Use an empty string if they are absent.
- `starts_new_document`: `true` if this page is the first page of a new logical document. Signals include a new title or header block, "Page 1 of N", or a change of facility or document type.

Call the `label_pages` tool **once**, with one entry per page, in page order. Do not skip pages. Pages marked `[no text available]` still need an entry. Give the best labels you can and treat them as continuations of the previous document unless there is evidence otherwise.
